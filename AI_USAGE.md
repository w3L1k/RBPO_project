# Использование генеративного ИИ

Генеративный ИИ использовался точечно в качестве консультационного инструмента при подготовке проектной документации. С его помощью обсуждались отдельные формулировки, структура документов, логика описания требований, модели угроз и проектных решений, а также выполнялся поиск возможных недочётов и несогласованностей в тексте.

При разработке MVP проекта генеративный ИИ также применялся для консультаций по отдельным техническим вопросам, обсуждения возможных вариантов реализации и помощи при поиске ошибок. Итоговые решения, код и документация проверялись участниками проекта самостоятельно.
